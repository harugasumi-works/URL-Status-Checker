# URL Status Checker 詳細設計書

## 1. クラス構成

| クラス | 責務 |
|---|---|
| `Main` | JavaFXアプリケーション起動 |
| `WindowInit` | メインウィンドウ初期化 |
| `UIFactory` | 画面部品・テーブル生成 |
| `ButtonFactory` | Scan / Save操作生成 |
| `UILogic` | URL一覧・結果の保持と画面更新 |
| `Operator` | URLチェック処理の実行 |
| `CustomJoin` | 並行タスク完了結果の収集 |
| `LinkBuilder` | HttpRequest / HttpClient生成 |
| `Report` | スキャン結果集計 |
| `ReturnOutput` | Reportと出力データの組み立て |
| `JsonDto` | JSON文字列への変換 |
| `CsvDto` | CSV文字列への変換 |
| `ExportFile` | OSの保存ダイアログ経由でファイル保存 |

## 2. URLチェック詳細

### 2.1 リクエスト生成

`LinkBuilder.requestFactory()`で以下を設定する。

- URL: `https://` + 入力値
- Method: GET
- Request timeout: 5秒
- User-Agent / Accept / Accept-Languageを設定

`HttpClient`は共有インスタンスを使用し、接続タイムアウトは10秒、HTTPバージョンは`HTTP_3`を指定する。

### 2.2 結果判定

`Operator.scanOperator()`でHTTPステータスを判定する。

```text
status < 400   → Success
400 <= status < 500 → Fail
status >= 500  → Fail
例外発生      → Fail（statusCode = 0）
```

Successでは経過時間をms単位で保持する。
Failでは失敗理由を保持する。

## 3. 並行実行詳細

`Operator.scanAll()`では、各`ScanRequest`を`Callable<ScanResult>`へ変換し、`StructuredTaskScope`へforkする。

`CustomJoin.onComplete()`で各タスク完了時に以下を行う。

1. タスク失敗なら`onTaskFailure`を呼び出す。
2. 正常終了なら`onResult`へ結果を通知する。
3. Successはsuccessesへ追加する。
4. Failはfailuresへ追加する。

全タスク完了後、`ExecutionResult`を返す。

## 4. 画面更新詳細

`UILogic`は以下を保持する。

```text
items      : URL一覧
indexById  : URLのidと一覧位置の対応
lastScan   : 最新のScanOutput
```

チェック完了時は`Platform.runLater()`を使用してJavaFX Application Thread上で一覧を更新する。

同一URLの再スキャンでは、既存行を`Pending`から`Scanned`へ置き換える。

## 5. 集計・出力詳細

### 5.1 集計

`Report.summarize()`で以下を算出する。

```text
total         = successes + failures
successCount  = successes件数
failureCount  = failures件数
```

### 5.2 JSON

`JsonDto.convert()`で`Report`全体をJSON化する。`stats`、successes、failuresを含む。

### 5.3 CSV

CSV列は以下とする。

```text
timeStamp,url,outcome,statusCode,latencyMs,reason
```

成功結果を先に出力し、その後に失敗結果を出力する。

### 5.4 保存

`ExportFile`の`FileChooser`で保存先をユーザーに選択させ、選択したファイルへ文字列を書き込む。

JSONとCSVの変換結果は`LazyConstant`で保持し、同一スキャン結果に対する再変換を避ける。

## 6. エラー処理

| 発生箇所 | 処理 |
|---|---|
| URL生成失敗 | Failへ変換 |
| 接続・通信失敗 | Failへ変換 |
| スキャン中断 | Failへ変換し割り込み状態を復元 |
| タスク異常終了 | `onTaskFailure`で通知 |
| 保存時のファイル書き込みI/Oエラー | `ExportFile.export()`内で`IOException`を捕捉し、エラー内容を表示する専用ウィンドウを開く |
| json()/csv()実行時のその他の例外 | `ButtonFactory`側の`catch (Exception e)`で捕捉し、`e.getMessage()`を含むPopUpを表示する |
