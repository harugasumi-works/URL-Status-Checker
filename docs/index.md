# URL Status Checker

Java 26 の構造化並行性とデータ指向プログラミング(DOP)で構築した、複数URLのステータスを並行チェックするデスクトップアプリケーションです。

## ドキュメント

- [要件定義書](要件定義書.md) — システムの目的、対象範囲、機能要件・非機能要件
- [基本設計書](基本設計書.md) — システム構成、画面設計、データ設計、主要処理の流れ
- [詳細設計書](詳細設計書.md) — クラス構成、並行実行・集計・出力の詳細、エラー処理

## 技術スタック

- Java 26(構造化並行性、sealed interface、レコード)
- JavaFX 26
- Jackson 3(JSON / CSV変換)
- Gradle
